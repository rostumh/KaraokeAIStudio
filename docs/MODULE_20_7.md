# Module 20.7 - Built-in Demucs and Guided Workflow

The Windows build now installs and bundles CPU PyTorch, torchaudio, SoundFile, Demucs, and a dedicated DemucsRunner executable. End users never install Python or optional requirements. The Studio page now presents a four-step guided workflow with progressive buttons: Import, Separate Vocals, Create Lyrics, and Render Video.
